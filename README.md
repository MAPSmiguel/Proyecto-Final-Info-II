## Descripción del Proyecto
Este proyecto consiste en el desarrollo de una aplicación en Python basada en la arquitectura Modelo–Vista–Controlador (MVC). La aplicación integra herramientas para la carga, procesamiento y análisis de información biomédica, incluyendo imágenes médicas, señales fisiológicas y datos tabulares.

Mediante una interfaz gráfica desarrollada con PyQt, el usuario puede interactuar con diferentes módulos especializados que permiten visualizar, procesar y analizar los datos de forma intuitiva.

## Funcionalidades Principales
**Módulo de Imágenes Médicas**
* Carga de archivos DICOM.
* Visualización de cortes axiales, coronales y sagitales.
* Conversión de imágenes a formato NIfTI.
* Operaciones de segmentación y procesamiento morfológico.
**Módulo de Señales Biomédicas**
* Carga de señales desde archivos .mat.
* Selección y visualización de canales.
* Adición de ruido a señales seleccionadas.
* Cálculo y visualización de promedio y desviación estándar sobre diferentes ejes.
**Módulo de Datos Tabulares**
* Carga de archivos CSV y Excel.
* Visualización de estadísticas descriptivas.
* Filtrado de columnas.
* Generación de gráficas tipo plot y scatter.

## Importancia del Proyecto

El análisis de datos biomédicos es una tarea fundamental en la bioingeniería y en las ciencias de la salud. Las imágenes médicas, las señales fisiológicas y los datos clínicos contienen información valiosa para apoyar procesos de diagnóstico, monitoreo y toma de decisiones.

Este proyecto busca integrar diferentes herramientas de procesamiento y visualización en una única aplicación, facilitando la exploración de datos biomédicos y fortaleciendo las competencias en programación, análisis de datos y desarrollo de software científico.
